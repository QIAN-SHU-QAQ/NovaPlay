一、项目概述
================================================================================

NovaPlay 是一个类似 Kazumi 的在线视频聚合播放器，支持多源抓取、在线播放、
视频下载。UI 全新设计，可跨平台运行并分发给其他用户使用。

核心定位：在线视频聚合播放器，支持多源抓取、在线播放、视频下载。


二、技术栈
================================================================================

┌──────────────┬─────────────────────┬──────────────────────────────┐
│ 组件          │ 选择                 │ 说明                          │
├──────────────┼─────────────────────┼──────────────────────────────┤
│ 框架          │ Flutter              │ 跨平台（Win/Android/Mac/Linux）│
│ 语言          │ Dart                 │ Flutter 标配                  │
│ 播放器        │ media_kit            │ 底层 mpv，支持网络流           │
│ 网络          │ dio + html           │ HTTP 请求 + 页面解析          │
│ 数据库        │ drift (SQLite)       │ 存储收藏、历史、源配置         │
│ 状态管理      │ Riverpod             │ 响应式状态管理                │
│ 下载          │ dio + 分块下载        │ 支持断点续传                  │
│ 弹幕          │ 自定义 Canvas 渲染    │                             │
└──────────────┴─────────────────────┴──────────────────────────────┘

五、多源系统设计
================================================================================

// 源的抽象接口，每个网站实现一个
abstract class BaseScraper {
  String get name;           // 源名称
  String get baseUrl;        // 网站地址

  Future<List<VideoModel>> getHome({int page});
  Future<List<VideoModel>> search(String keyword, {int page});
  Future<VideoDetail> getDetail(String url);
  Future<List<String>> getPlayUrls(String episodeUrl);
  Future<List<DanmakuItem>> getDanmaku(String episodeUrl);
}
